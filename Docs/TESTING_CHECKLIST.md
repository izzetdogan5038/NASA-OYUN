# Testing Checklist

## Functional
- [ ] Proje aciliyor, modul compile oluyor.
- [ ] DataTable'lar ic ice aktarildi, satirlar gorunuyor.
- [ ] Gorev secimi -> designer aciliyor.
- [ ] Enstruman secimi kaynaklari guncelliyor.
- [ ] Bus bileşeni secimi kaynaklari guncelliyor.
- [ ] Firlatıcı secimi kapasiteyi guncelliyor.
- [ ] Yörünge secimi omru guncelliyor.
- [ ] Validation: mass/power/budget/data/comms/lifetime kontrolu calisiyor.
- [ ] Gecersiz tasarımda "Run Simulation" devre disi.
- [ ] Simulasyon: timeline + event log + ses/VFX.
- [ ] Skor ekranı: grade + alt skorlar + analiz.
- [ ] SaveGame: tasarim kaydediliyor ve yukleniyor.

## Multiplayer
- [ ] Host/Join calisiyor.
- [ ] Rol secimi senkronize.
- [ ] Tasarim kilitleme senkronize.
- [ ] 2/3/4 oyuncu testi.

## Performance
- [ ] 60 FPS (mid-range PC).
- [ ] Bellek < 4GB.

## Edge cases
- [ ] Max kutle, sifir guc, sifir butce.
- [ ] Hic enstruman secmeden simulasyon.
- [ ] Cok fazla event (kotu senaryo).
